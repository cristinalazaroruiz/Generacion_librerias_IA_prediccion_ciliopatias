# Generacion_librerias_IA_prediccion_ciliopatias
*Codigo asociado a mi trabajo final de máster (TFM) sobre el uso de Inteligencia Artificial para el diagnóstico de ciliopatías*

En este repositorio se incluyen todos los scripts (en R y Python) utilizados para llevar a cabo el estudio sobre el uso de Inteligencia Artificial para el diagnóstico de ciliopatías.
Los diferentes algoritmos de IA se han llevado a cabo mediante librerías de R. Se han aplicado tanto algoritmos de aprendizaje no supervisado (PCA, tSNE, clustering) como algoritmos de aprendizaje supervisado () utilizando datos recopilados de diferentes bases de datos y trabajos públicos, como CiliaMiner u OMIM.
